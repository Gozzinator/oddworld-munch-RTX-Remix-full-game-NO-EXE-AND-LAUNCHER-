# oddworld-munch-RTX-Remix-full-game-NO-EXE-AND-LAUNCHER-
This project brings full ray tracing (path tracing) and updated materials to Oddworld: Munch's Oddysee using NVIDIA's RTX Remix platform. By utilizing the Remix runtime, the mod intercepts the game's original draw calls to inject modern lighting, shadows, and physically-based rendering into the classic Oddworld environment.
